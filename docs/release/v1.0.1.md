# iqdb-types v1.0.1

A fix release. No API changes.

## Security

- **Deserialization keeps the type invariants.** `Vector::new` rejects empty
  and non-finite vectors and `VectorId::try_from` rejects an empty byte key,
  but the derived `serde` impls accepted both. A binary format can carry NaN,
  and any format can carry `[]`, so a deserialized value could break the
  promise every index relies on. `Vector` now deserializes through
  `Vector::new` and `VectorId::Bytes` through `VectorId::try_from`, returning
  a deserialization error on bad input. The wire format is unchanged, so
  existing data reads back as before.

## Upgrading

Change the version to `1.0.1`. Nothing else is needed.
